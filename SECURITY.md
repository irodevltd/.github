# Security policy

If you find a security problem in any İrodev project, please email **info@irodev.net** instead of opening a public
issue. Include the project, the version and the steps to reproduce it. We reply within two business days and credit
you in the release notes if you wish.

Bir güvenlik sorunu bulursanız lütfen herkese açık bir issue açmak yerine **info@irodev.net** adresine yazın. Projeyi,
sürümü ve sorunu tekrar oluşturma adımlarını ekleyin. İki iş günü içinde yanıt veririz; isterseniz sürüm notlarında
adınızı anarız.
